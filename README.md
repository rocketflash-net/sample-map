# Place data sample

Interactive map of 30 Southeast Asian places (Bali, Yogyakarta, Chiang Mai, Hoi An, Luang Prabang, Penang), each with a researched record and an audited map pin.

- **Live map:** https://rocketflash-net.github.io/sample-map/
- **Data:** [`data/`](data/) as XLSX (places, pin audit, field guide), CSV and GeoJSON

Prepared by Daniel Aldo as an independent sample for Orbeal; not affiliated with or endorsed by Orbeal.
Sources: OpenStreetMap contributors (ODbL), Wikipedia/Wikidata, UNESCO. Map tiles © Esri.
